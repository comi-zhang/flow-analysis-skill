# 收支口径定义

个人流水分析里，"花了多少"至少有四个不同答案。混淆它们是绝大多数错误结论的来源。

## 四个口径

| 口径 | 定义 | 回答的问题 |
| --- | --- | --- |
| 原始汇总 | 所有"支出"方向记录求和 | （几乎没用，含大量空转） |
| **真实支出** | 账户真实的资金流出 | 我账户流出了多少钱 |
| **真实消费** | 真实支出中真正花掉、不会回来的部分 | 我实际花掉多少钱 |
| 净结余 | 真实收入 − 真实支出 | 现金流是否为正 |

## 真实支出：排除"假交易"

这些记录方向是支出，但**不是真实发生的资金流动**：

| 类型 | 例子 | 为什么要排除 |
| --- | --- | --- |
| 内部划转 | 自己账户 A → 自己账户 B | 同一笔钱在自己名下移动 |
| 重复记账 | 同一笔在平台和银行各记一次 | 否则金额翻倍 |
| 交易未成功 | 支付失败、已关闭、冲正 | 钱没出去 |
| 清算过渡 | 待清算、过渡户 | 中间态，不是最终状态 |
| 已确认的退款对冲 | 支付 + 退款配对成功 | 净额为 0 |

判定这些字段通常来自来源系统。如果来源没有标注，需要自己推导：
内部划转看对手是否为本人账户；重复记账靠跨渠道去重（见 SKILL.md 步骤 4）。

## 真实消费：再排除"真但非消费"

这些是真实的资金流出，但**不是消费**：

| 类型 | 为什么不算消费 |
| --- | --- |
| 金融理财 | 申购基金/理财是**资产形态转换**，钱还在你名下 |
| 转账划转 | 转到别处，不是消耗 |
| 人情往来 | 给家人朋友的转账（**口径可争议，见下**） |

典型例子：从活期转 1 万进货币基金。

- 真实支出 **+10,000**（账户余额确实少了）
- 真实消费 **+0**（钱还是你的，只是从银行卡变成基金）

赎回时收入 +10,000，一来一回在"收入/支出"里各滚动一次，但财富没有变化。
**只有真实消费能过滤掉这种空转。**

### 「人情往来」怎么定：必须问用户

这是口径里最大的分歧点，两种定义都合理：

- **不算消费**（默认）：给父母/朋友的转账是资金转移，不是消耗
- **算消费**：如果这笔钱的用途就是花掉（如给家人生活费），那它是消费

实测差异：某用户真实支出 118 万，按"不算消费"是 26.1 万，按"算消费"是 40.9 万——
**差 57%**。所以这个选择必须由用户拍板，不能默认。

## 算完之后再修四类虚高

即使口径正确，消费仍会虚高，因为来源数据有问题：

### 1. 退款未对冲

摘要写着「已全额退款」或「已退款(¥736.00)」，但退款腿没有配上对，整笔仍计入消费。

```
识别：原始摘要匹配 已全额退款 | 已退款\(¥([\d,\.]+)\)
处理：全额退款的整笔剔除；部分退款扣减退款额
```

### 2. 银行计息混入

对手或摘要含「应付利息-应付个人活期存款利息」「结息」——**这是银行给你计息**，
被当成"支出"记录下来了。

### 3. 跨渠道重复

见 SKILL.md 步骤 4 的四条判据。

### 4. 已报销支出

支出发生后短期内，他人汇入等额款项（报销/代付）。
**数据里看不出来，必须问用户。** 识别线索：同金额、相隔数天、对方是同事/导师/公司。

### 5. 分类错误（不影响总额，影响结构）

常见：学校「代收扣款」被归到餐饮美食，实际是学费+住宿费。
检查方法：看每个大类里金额最大的几笔，人工扫一眼是否合理。

## 报告时怎么说

1. **给出差额**，不要只给一个数。"真实支出 118 万 / 真实消费 26 万 / 差额是理财和互转"
   ——差额本身是用户最需要知道的信息。
2. **标出修正项**。给出「现行值 / 修正值 / 调整明细」，让用户能复核。
3. **说明剔除规则**。数字离开口径说明就失去意义，看板上也要写。
4. **单笔中位数和均值一起给**。中位数被小额拉低、均值被大额拉高，单看任一个都会误判结构。

## 交叉验证

- **笔数与密度**：日均笔数是否符合用户生活节奏（学生 5–6 笔/天，上班族更少）
- **单笔均值**：餐饮 15–20 元、交通 10–15 元，明显偏离要查
- **余额链**：见 SKILL.md 步骤 3，是验证金额可信度的硬证据
- **Top N 占比**：如果 Top50 占了一半以上，说明数字被少数大额撑起，要逐个核对
